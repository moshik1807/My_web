# Vision Window: מה היה כאן פעם?

מכוונים את המצלמה לסביבה ובוחרים שנה בין 1880 ל-2050.

- **אוטומטי ורציף:** כל עוד המצלמה פתוחה, האפליקציה מצלמת את המבט הנוכחי ושולחת אותו למודל AI לעריכת תמונות, בלי צורך ללחוץ על כלום. המודל בונה את כל הסצנה מחדש כפי שהייתה נראית בשנה שנבחרה, בפנים ובחוץ: בניינים, רחוב, אנשים ובגדים, כלי רכב, רהיטים וחפצים. מחשב הופך למכונת כתיבה, טלפון לטלפון חוגה, ומכונית לכרכרה. כל תמונה חדשה מחליפה את הקודמת במעבר רך.
- **עד שהתמונה הראשונה מוכנה:** המצלמה מוצגת בגוון הצילום של התקופה.
- **כפתור עצירה/המשך:** עוצר את העדכון האוטומטי. העדכון נעצר גם כשהאפליקציה ברקע.
- **עדשת רנטגן:** מראה את ההווה בתוך התמונה מהעבר.
- **מיקום:** ה-GPS ו-OpenStreetMap קובעים את האזור (ארץ ישראל והלבנט, אירופה או צפון אמריקה), ואיתו את הבגדים, כלי הרכב והבנייה של כל תקופה.

**אתר חי:** https://moshik1807.github.io/My_web/

### מנועי AI

| מנוע | מפתח | עלות | הערות |
|---|---|---|---|
| חינמי (ברירת מחדל) | לא צריך | חינם | FLUX.1 Kontext ב-Hugging Face Space ציבורי. כל תמונה לוקחת 20–60 שניות, ויש מכסה יומית. טוקן חינמי של Hugging Face מגדיל את המכסה. |
| Google Gemini | מפתח מ-aistudio.google.com | בתשלום לפי תמונה | מהיר ואיכותי |
| OpenAI | מפתח מ-platform.openai.com | בתשלום לפי תמונה | |

המפתח נשמר רק בדפדפן. אפשר גם להגדיר `GEMINI_API_KEY` בשרת, ואז הבקשות עוברות דרכו.

| קובץ | תפקיד |
|---|---|
| `client/src/main.js` | מעטפת האפליקציה: מצלמה, סרגל זמן, מיקום, הלולאה האוטומטית, הגדרות |
| `client/src/live.js` | תצוגת המצלמה: גוון התקופה, מעבר רך בין תמונות ה-AI, עדשת רנטגן |
| `client/src/ai.js` | בניית ההנחיה ושליחה למנוע (Hugging Face, Gemini או OpenAI) |
| `client/src/periods.js` | איך נראה כל אזור בכל תקופה |
| `client/src/location.js` | GPS, שם המקום ואתרים היסטוריים בסביבה |
| `server/` | Node + PostGIS: API מרחבי ונתיב AI עם מפתח בשרת |

## הרצה

### רק הלקוח

```bash
cd client && python3 -m http.server 8000
# http://localhost:8000
```

מצלמה ומיקום דורשים HTTPS או localhost.

### מערכת מלאה

```bash
GEMINI_API_KEY=... docker compose up --build   # המפתח לא חובה
# http://localhost:8080
```

### בדיקות

```bash
cd server && npm install
DATABASE_URL=postgres://... npm test
```

## API

| נתיב | תיאור |
|---|---|
| `GET /api/health` | בדיקת חיים, גרסת PostGIS, והאם מוגדר AI בשרת |
| `GET /api/locations/nearby?lat&lng&radius` | אתרים ברדיוס, ממוינים לפי מרחק |
| `GET /api/locations/:id/assets?year&lod` | נכסים תלת-ממדיים שתקפים לשנה |
| `GET /api/locations/:id/paths?year` | מסלולי תנועה כ-GeoJSON |
| `GET /api/locations/:id/timeline` | כל התקופות של אתר |
| `POST /api/ai/transform` | ‏`{image, mime, prompt}` → תמונה ערוכה (דרך `GEMINI_API_KEY`) |
| `WS /ws` | שולחים `{type:"pose", lat, lng, year}` ומקבלים מניפסט נכסים |

## מגבלות ידועות

- **מהירות:** כל תמונה לוקחת כמה שניות, ולכן הסביבה מתעדכנת כל כמה שניות ולא כווידאו חי.
- **מכסה:** המנוע החינמי מוגבל במכסה יומית, ועדכון רציף מנצל אותה מהר. טוקן חינמי של Hugging Face מגדיל אותה.
- **התיישרות:** כשהמצלמה זזה בזמן שהמנוע עובד, התמונה מהעבר לא תתיישר בדיוק עם מה שרואים.
- **המנוע החינמי:** תלוי בשרת ציבורי של Hugging Face, שיכול להיות עמוס או לא זמין.
- **דיוק היסטורי:** התוצאה היא הדמיה של המודל, ולא שחזור היסטורי מדויק.
