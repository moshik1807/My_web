# Vision Window: מה היה כאן פעם?

מכוונים את המצלמה לרחוב ובוחרים שנה, והאפליקציה מראה את אותו מקום בתקופה ההיא:

- **אנשים** שהמצלמה רואה מקבלים בגדים מהתקופה, שזזים איתם ונשארים צמודים לגוף. למשל גלביה ותרבוש או כאפייה ב-1880, חליפה ופדורה ב-1920, כובע טמבל ב-1970.
- **כלי רכב** מוחלפים בכלי תחבורה מהתקופה, באותו מקום ובאותו גודל. אופנוע עם רוכב הופך לחמור עם רוכב, מכונית לכרכרה או למכונית מודל T, ואוטובוס לעגלת משא או לאוטובוס ישן.
- **ריהוט רחוב** מוחלף גם הוא: ספסל הופך לאבן גיר או לספסל עץ, ורמזור לפנס נפט או לפנס גז.
- **התמונה כולה** מקבלת את המראה של צילום מאותה תקופה: הדפס אלבומין בגוון ספיה ל-1880, שחור-לבן אורתוכרומטי ל-1920, קודאכרום דהוי ל-1970.
- **המיקום** (GPS, OpenStreetMap ו-Wikipedia) קובע אילו בגדים ואילו כלי רכב מתאימים. ארץ ישראל והלבנט, אירופה וצפון אמריקה מקבלות כל אחת פרופיל משלה.

**אתר חי:** https://moshik1807.github.io/My_web/

## שתי שכבות של מציאותיות

| | תצוגה חיה | "צלם מהעבר" |
|---|---|---|
| מה זה | עיבוד בזמן אמת במכשיר | עריכת תמונה במודל AI גנרטיבי |
| מהירות | בכל פריים | 10–30 שניות לתמונה |
| מראה | מודלים ובגדים מצוירים, מעל צילום אמיתי | צילום מציאותי |
| עלות | חינם, הכול במכשיר | לפי התעריף של הספק (Gemini או OpenAI) |
| קשר למצלמה | זיהוי תנוחה ואובייקטים: כל אדם, רכב וספסל מוחלפים במקומם | ההנחיה למודל נבנית ממה שזוהה ("האדם משמאל יושב על ספסל → אבן גיר") |

התצוגה החיה לא יכולה להחליף בגדים בצורה ריאליסטית לגמרי, כי זה דורש מודל גנרטיבי שלא רץ בזמן אמת בדפדפן. לכן היא מראה מיד את הרעיון, ו"צלם מהעבר" נותן את התוצאה המציאותית.

### מפתח AI

בלחיצה על "הגדרות AI" מזינים מפתח של Google Gemini (מ-https://aistudio.google.com/apikey) או של OpenAI. המפתח נשמר רק בדפדפן. אפשר גם להגדיר אותו בשרת (`GEMINI_API_KEY`), ואז הלקוח שולח את הבקשות דרך השרת והמפתח לא מגיע לדפדפן בכלל.

## איך זה עובד

```
מצלמה ─┬─► MediaPipe Pose (עד 4 אנשים, כולל מסכות גוף)  ─┐
       └─► MediaPipe Object Detector (רכבים, ספסלים, רמזורים) ─┤
                                                             ▼
                       מעקב (IoU) → כל אדם או אובייקט שומר על אותה תחפושת או מודל
                                                             ▼
   פרופיל תקופה (אזור × שנה) ← GPS → OpenStreetMap / Wikipedia
                                                             ▼
   הרכבה ב-WebGL: מחיקת האובייקט המקורי → מודל תלת-ממדי מהתקופה → האנשים מעל
   → צביעה מחדש של הבגדים → בגדים וכובעים לפי שלד הגוף → גוון הצילום של התקופה
                                                             ▼
                                   עדשת רנטגן: העבר בתוכה, ההווה מחוצה לה
```

| קובץ | תפקיד |
|---|---|
| `client/src/main.js` | מעטפת האפליקציה: מצבים, סרגל זמן, מיקום, חלונות |
| `client/src/ar.js` | מנוע התצוגה החיה וה-shader שמרכיב את התמונה |
| `client/src/vision.js` | MediaPipe: תנוחת גוף, מסכות לכל אדם, זיהוי אובייקטים |
| `client/src/tracker.js` | מעקב שנותן לכל זיהוי מזהה קבוע לאורך הפריימים |
| `client/src/costume.js` | ציור בגדים וכובעים לפי נקודות השלד |
| `client/src/models.js` | מודלים תלת-ממדיים: חמור, סוס, גמל, כרכרה, מכוניות, ספסלים, פנסים |
| `client/src/periods.js` | מה לבשו, במה נסעו ועל מה ישבו, לכל אזור ותקופה |
| `client/src/location.js` | GPS, שם המקום ואתרים היסטוריים בסביבה |
| `client/src/ai.js` | בניית ההנחיה ושליחה ל-Gemini או ל-OpenAI |
| `client/src/scene3d.js` | השחזור התלת-ממדי של כיכר השעון ביפו (מצב "יפו בתלת-ממד") |
| `server/` | Node + PostGIS: API מרחבי, הזרמת נכסים ב-WebSocket, ונתיב AI עם מפתח בשרת |

## הרצה

### רק הלקוח

```bash
cd client && python3 -m http.server 8000
# http://localhost:8000
```

מצלמה ומיקום דורשים HTTPS או localhost.

### מערכת מלאה

```bash
GEMINI_API_KEY=... docker compose up --build   # המפתח לא חובה
# http://localhost:8080
```

### בדיקות

```bash
cd server && npm install
DATABASE_URL=postgres://... npm test
```

## API

| נתיב | תיאור |
|---|---|
| `GET /api/health` | בדיקת חיים, גרסת PostGIS, והאם מוגדר AI בשרת |
| `GET /api/locations/nearby?lat&lng&radius` | אתרים ברדיוס, ממוינים לפי מרחק |
| `GET /api/locations/:id/assets?year&lod` | נכסים תלת-ממדיים שתקפים לשנה |
| `GET /api/locations/:id/paths?year` | מסלולי תנועה כ-GeoJSON |
| `GET /api/locations/:id/timeline` | כל התקופות של אתר |
| `POST /api/ai/transform` | ‏`{image, mime, prompt}` → תמונה ערוכה (דרך `GEMINI_API_KEY`) |
| `WS /ws` | שולחים `{type:"pose", lat, lng, year}` ומקבלים מניפסט נכסים |

## מגבלות ידועות

- **מיקום מדויק במרחב:** אין VPS, ולכן התקופה והאזור נקבעים לפי GPS, אבל המודלים מעוגנים לתמונה ולא לקואורדינטות בעולם.
- **זיהוי:** המודלים במכשיר מזהים עד 4 אנשים, ומפספסים אנשים קטנים מאוד או מוסתרים חלקית.
- **אזורים:** הפרופילים מכסים את ארץ ישראל והלבנט, אירופה וצפון אמריקה. בכל מקום אחר האפליקציה משתמשת בפרופיל כללי.
- **הגדרות שחזור:** כל הבגדים, המודלים והשחזורים נבנים בקוד לצורכי הדגמה, ואינם שחזור היסטורי מדויק.
