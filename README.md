# Vision Window: מה היה כאן פעם?

מכוונים את המצלמה לסביבה ובוחרים שנה בין 1880 ל-2050.

- **בזמן אמת, במכשיר:** כל פריים מהמצלמה מחולק לאזורים: שמיים, בניינים, כביש, מדרכה, צמחייה, כלי רכב, אנשים, ועמודים ושלטים. החלוקה נעשית במודל SegFormer שאומן על 150 קטגוריות של מרחב עירוני (ADE20K), ורץ בדפדפן עם ONNX Runtime (WebGPU או WebAssembly). כל אזור נבנה מחדש לפי התקופה:
  - השמיים הופכים לשמיים של התקופה, עם אובך ועננים.
  - הקירות הופכים לאבן מסותתת, לטיח או לבטון.
  - הכביש הופך לדרך עפר עם תלמי גלגלים, לאבני מרצפת או לאספלט ישן, בפרספקטיבה נכונה.
  - המדרכה הופכת ללוחות אבן או לאדמה.
  - כלי רכב, עמודים ושלטים נמחקים, והחומר שסביבם ממלא את מקומם.
  - הבגדים של האנשים נצבעים בצבעי התקופה.
  - האור והצללים של המצלמה נשמרים על כל חומר, ועל הכול נוסף המראה של צילום מאותן שנים.
- **בלחיצה על "הפכו לעבר":** כל הסביבה נבנית מחדש כפי שנראתה בשנה שנבחרה, ולא רק פריטים בודדים. זה כולל את הרחוב, הבניינים, הצמחייה, השלטים, האנשים וכלי הרכב. מודל AI לעריכת תמונות מקבל את הפריים מהמצלמה ושומר על אותה זווית ואותה פרספקטיבה, כך שהתמונה מהעבר מתיישרת עם מה שרואים.
- **מצב רציף:** ברגע שתמונה אחת מוכנה, האפליקציה מצלמת את המבט הנוכחי ובונה את הבאה.
- **עדשת רנטגן:** מראה את ההווה בתוך התמונה מהעבר. אפשר לגרור אותה ולשנות את גודלה בצביטה.
- **מיקום:** ה-GPS, OpenStreetMap ו-Wikipedia קובעים איך נראה האזור בכל תקופה. יש פרופיל לארץ ישראל והלבנט, לאירופה ולצפון אמריקה.

### מנועי AI

| מנוע | מפתח | עלות | הערות |
|---|---|---|---|
| חינמי (ברירת מחדל) | לא צריך | חינם | FLUX.1 Kontext ב-Hugging Face Space ציבורי. כל תמונה לוקחת 20–60 שניות, ויש מכסה יומית. טוקן חינמי של Hugging Face מגדיל את המכסה. |
| Google Gemini | מפתח מ-aistudio.google.com | בתשלום לפי תמונה | מהיר ואיכותי |
| OpenAI | מפתח מ-platform.openai.com | בתשלום לפי תמונה | |

המפתח נשמר רק בדפדפן. אפשר גם להגדיר `GEMINI_API_KEY` בשרת, ואז הבקשות עוברות דרכו.

| קובץ | תפקיד |
|---|---|
| `client/src/main.js` | מעטפת האפליקציה: מצלמה, סרגל זמן, מיקום, מצב רציף, הגדרות |
| `client/src/scene.js` | הבנת הסצנה: SegFormer/ADE20K ב-ONNX Runtime, קיבוץ ל-8 סוגי אזורים, מחיקת רכבים ועמודים |
| `client/src/live.js` | בנייה מחדש של כל אזור בחומרים של התקופה (shader), גוון הצילום, תמונת ה-AI, עדשת רנטגן |
| `client/src/ai.js` | בניית ההנחיה ושליחה למנוע (Hugging Face, Gemini או OpenAI) |
| `client/src/periods.js` | איך נראה כל אזור בכל תקופה |
| `client/src/location.js` | GPS, שם המקום ואתרים היסטוריים בסביבה |
| `server/` | Node + PostGIS: API מרחבי ונתיב AI עם מפתח בשרת |

## הרצה

### רק הלקוח

```bash
cd client && python3 -m http.server 8000
# http://localhost:8000
```

מצלמה ומיקום דורשים HTTPS או localhost.

### מערכת מלאה

```bash
GEMINI_API_KEY=... docker compose up --build   # המפתח לא חובה
# http://localhost:8080
```

### בדיקות

```bash
cd server && npm install
DATABASE_URL=postgres://... npm test
```

## API

| נתיב | תיאור |
|---|---|
| `GET /api/health` | בדיקת חיים, גרסת PostGIS, והאם מוגדר AI בשרת |
| `GET /api/locations/nearby?lat&lng&radius` | אתרים ברדיוס, ממוינים לפי מרחק |
| `GET /api/locations/:id/assets?year&lod` | נכסים תלת-ממדיים שתקפים לשנה |
| `GET /api/locations/:id/paths?year` | מסלולי תנועה כ-GeoJSON |
| `GET /api/locations/:id/timeline` | כל התקופות של אתר |
| `POST /api/ai/transform` | ‏`{image, mime, prompt}` → תמונה ערוכה (דרך `GEMINI_API_KEY`) |
| `WS /ws` | שולחים `{type:"pose", lat, lng, year}` ומקבלים מניפסט נכסים |

## מגבלות ידועות

- **מהירות:** בטלפון עם WebGPU מפת הסצנה מתעדכנת בערך 10–20 פעמים בשנייה. בלי WebGPU היא מתעדכנת 2–4 פעמים בשנייה, ולכן בתנועה מהירה הקצוות מפגרים מעט אחרי הווידאו. צילום ה-AI לוקח שניות לכל תמונה.
- **מודל הסצנה:** בכניסה הראשונה מורדים כ-15MB מ-Hugging Face.
- **התיישרות:** כשהמצלמה זזה בזמן שהמנוע עובד, התמונה מהעבר לא תתיישר בדיוק עם מה שרואים.
- **המנוע החינמי:** תלוי בשרת ציבורי של Hugging Face, שיכול להיות עמוס או לא זמין.
- **דיוק היסטורי:** התוצאה היא הדמיה של המודל, ולא שחזור היסטורי מדויק.
